## A Simulator for Robot-Fleet Decentralized Package Management 

## Features
- **Async Agents:** Asynchronous on-robot update agents, spawned via async `tokio` tasks.
- **Decentralized Communication:** Desired package state and messages propagate through the fleet via gossip protocols.
- **Offline Package Transfer:** Robot-to-robot robust package transfer through content-addressed memory.
- **Simulated Package Installation:** Per-robot package installation state machine, with staging, rollback, and health check routines.
- **Radio Communication:** Simulates lossy radio range-based communication.

## Installation Instructions

```bash
# 1. Clone the repo
git clone https://github.com/Sherif-Sameh/fleet_sim
cd fleet_sim
# 2. Compile with Cargo
cargo build
```
After installation, you can run a simple script via [`main.rs`](src/main.rs) that simulates 5 robots in a chain, with the desired package state moving along it.

```bash
# Run executable generated by Cargo
./target/debug/fleet_sim
# Or rebuild and run with Cargo
cargo run
```

## Layout

| Module      | Contents                                                        |
|-------------|----------------------------------------------------------------------|
| `types`     | `RobotId`, `PackageState`, `Package`, `Version`, `ContentHash`               |
| `error`     | `AgentError` (`thiserror`) + `Result` alias                            |
| `state`     | `UpdateState` enum + `UpdateEvent`, pure `apply()` transition fn     |
| `message`   | `Message` + `RobotStatus` (serde-ready for real comms.)               |
| `store`     | `Store` trait + `Blob` (for raw packages)    |
| `memory`    | `MemoryStore` (impl `Store`)    |
| `transport` | `Transport` trait (robot-to-robot comms.)                                        |
| `radio`     | `RadioTransport` / `RadioNetwork` (impl `Transport`)     |
| `agent`     | `AgentHandle`/ `Agent` (owns all state, `select!` over cmds/msgs/timers)      |
